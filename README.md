# BugSync

BugSync is a full-stack collaborative debugging platform where developers can post programming issues, share solutions, and mark accepted fixes.

The platform is designed to help students and developers understand programming errors through community-based debugging instead of only copying corrected code.

## Features

- User registration and login
- Password hashing for secure authentication
- Post programming bugs
- Add bug description, code, error message, and expected output
- View all community bugs
- Open detailed bug pages
- Submit solutions to bugs
- View community solutions
- Bug owner can accept a solution
- Automatically change bug status from `OPEN` to `SOLVED`
- User-specific actions
- Responsive and professional UI
